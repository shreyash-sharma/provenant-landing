## Editorial Standard

Keep the public docs specific. Say what the product does, what data it uses, where it stores state, and what a number means. Do not publish broad marketing claims unless the page links the claim to a measurement.

When a feature is local-only, say local. When a metric is observational, say observed. When setup depends on another tool such as `ccusage`, show the command and the fallback behavior.
